# Sistema de Desconto Progressivo 🏷️

Este é um programa desenvolvido em Python para calcular descontos progressivos em compras com base na quantidade de itens ou valor total.

## 🚀 Tecnologias Utilizadas
- **Python 3**

## 💻 Como Funciona
O script `desconto.py` recebe os dados da compra e aplica a regra de desconto correspondente:
- **Desconto leve:** para compras acima de determinado valor/quantidade inicial.
- **Desconto médio:** para volumes intermediários.
- **Desconto máximo:** para compras de grande volume.
